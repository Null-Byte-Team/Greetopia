## Hard rules
- The ML model must never publish pump commands. Vision output is an uncertain observation and a species is only a *candidate* until the user confirms it.
- Sensor failure, stale data or unknown weather must never trigger watering; missing weather is not "0% rain".
- Firmware limit: 15 s per command. A command with no acknowledgement is recorded as unconfirmed and is **never** retried automatically.
- Do not claim water savings, growth or accuracy without measured data; label simulated vs experimental results.
- Never commit secrets. Keep all timestamps UTC. Keep EN/AR i18n key parity.
- Add automated tests for everything you add; run them and report real results. Say clearly what you could not verify.
